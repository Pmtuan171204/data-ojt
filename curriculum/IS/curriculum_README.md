# Ý nghĩa các cột trong curricula_is.csv

| Cột | Ý nghĩa |
|---|---|
| `curriculum_code` | Mã khung chương trình theo nguồn của trường, giữ nguyên dấu gạch dưới và dấu gạch nối. |
| `curriculum_name` | Tên khung chương trình được chuẩn hóa cách diễn đạt tiếng Việt. |
| `specialization` | Chuyên ngành áp dụng: Hệ thống thông tin. |
| `total_credits` | Tổng tín chỉ toàn chương trình được hiển thị trong danh sách khung của trường. |
