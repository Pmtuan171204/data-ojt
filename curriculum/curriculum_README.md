# Ý nghĩa các cột trong curricula_all.csv

| Cột | Ý nghĩa |
|---|---|
| `curriculum_code` | Mã khung duy nhất, giữ đúng nguồn; dùng để liên kết với sinh viên. |
| `curriculum_name` | Tên chương trình chuẩn hóa tiếng Việt. |
| `specialization` | Chuyên ngành: Kỹ thuật phần mềm, Hệ thống thông tin, An toàn thông tin hoặc Trí tuệ nhân tạo. |
| `total_credits` | Tổng tín chỉ hiển thị trong ảnh nguồn của từng khung. |
