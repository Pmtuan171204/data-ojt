# Ý nghĩa các cột trong curricula_se.csv

| Cột | Ý nghĩa |
|---|---|
| `curriculum_code` | Mã khung chương trình theo nguồn của trường; giữ nguyên dấu gạch dưới trong mã. |
| `curriculum_name` | Tên khung chương trình, chuẩn hóa cách diễn đạt tiếng Việt. |
| `specialization` | Chuyên ngành áp dụng: Kỹ thuật phần mềm. |
| `total_credits` | Tổng tín chỉ toàn chương trình được hiển thị trong danh sách khung của trường. |
